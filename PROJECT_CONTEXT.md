# Project Context - Mahwar Ecosystem

## 1. Project Identity

Project Name:
Mahwar (منظومة محور)

Role:
A sovereign ecosystem for building, operating, and connecting independent digital systems.

Owner:
Project Owner and Vision Holder.

The project is not a single application.
It is an ecosystem containing independent systems that share infrastructure and exchange governed data.

---

# 2. Core Philosophy

The main principle:

Independent systems + Shared infrastructure + Sovereign data governance.

Each system must remain independent:

- Own code
- Own database
- Own deployment
- Own business logic
- Own lifecycle

Shared infrastructure is only a host and service layer.

---

# 3. Mahwar Factory Concept

Mahwar Factory is a system factory concept.

Its purpose:

- Build systems faster.
- Avoid rebuilding the same capabilities repeatedly.
- Generate new independent systems from reusable components.
- Maintain architectural governance.

The factory is not a replacement for business systems.
It is the environment that creates and manages them.

---

# 8. Working Rules

Before modifying anything:

1. Understand current state.
2. Review existing files.
3. Explain impact.
4. Propose solution.
5. Wait for approval when changes are significant.


Never:

- Delete important files without approval.
- Replace existing systems without analysis.
- Start from zero without justification.
- Ignore existing architecture decisions.
